## 📊 Activity 1: Dataset Analyses

1. **CSM Dataset (Conventional and Social Media Movies)**

   * Preprocessing and data cleaning
   * Train/validation split
   * Model selection for predicting **Gross** revenue
   * Assumption testing and transformations (Box-Cox / nonparametric if needed)
   * Prediction and comparison with actual values

2. **All-GPUs Dataset**

   * Preprocessing and descriptive statistics
   * Train/validation split
   * Predict GPU price/performance from technical specs
   * Performance-to-price trend over time
   * Manufacturer comparison
   * ANOVA analysis on **Pixel Rate**
